# Гусь — семейный XMPP-помощник

Гусь общается с детьми в привычном чате, помогает разобраться с домашними заданиями и получает расписание занятий из настроенного источника. Владелец сохраняет возможность писать от имени Гуся вручную.

**Статус: подготовлено техническое задание. Приложение и установочные скрипты пока не реализованы.**

## Основные решения

- Клиенты: Gajim и Conversations; сервер: существующий Prosody.
- Размещение: небольшой Python-сервис на Ubuntu 24.04 VDS; запуск через systemd.
- Генерация ответов: внешний API модели. Провайдер ещё не выбран.
- Отдельные контекст, профиль и режим общения для каждого XMPP-пользователя.
- Номер класса, учебный год и привязка к расписанию — изменяемые настройки профиля. Сейчас нужны уровни 2-го и 7-го классов.
- Управляющие команды доступны только владельцу. Ручной режим действует отдельно на каждый разговор.
- Источник расписания: сайт https://ivancher.ru/. Контракт интеграции уточняется после просмотра исходников версии для двух классов.

## Первая задача

Начать с [этапа 1](docs/tasks/01-xmpp-foundation.md): тестовый XMPP-аккаунт, проверка шифрования и синхронизации, настройки и диагностические команды. Подключение модели, автоматические ответы детям и интеграция расписания выполняются следующими этапами.

Будущие `install.sh`, `update.sh` и `doctor.sh` описаны в заданиях. Команд установки работающего бота пока нет.

## Где хранятся данные

В Git находятся исходники, документация и примеры. Рабочие профили, переписка, секреты, ключи OMEMO и резервные копии хранятся на VDS отдельно от каталога исходников. Обновление приложения должно сохранять их.
