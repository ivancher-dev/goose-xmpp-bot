# Языковые комментарии 0.3.5–0.3.7: проверки

[Инструкция и ограничения](LANGUAGE_FEEDBACK.md),
[задание](tasks/03b-language-feedback.md).

Добавлена SQLite-таблица language_feedback с отдельными enabled/mode/max_notes
для каждого профиля. По умолчанию выключено, brief, максимум два замечания.
Миграция 4 → 5 транзакционная. Старые данные и ключи сохраняются, прямой откат
к старой схеме не выполняется. Новые зависимости не добавлены.

Право `!admin language` проверяет код до модели. Смена настройки увеличивает
ревизию и отменяет ожидающие ответы только этого диалога. Включение разбора
не меняет manual/auto. Модель не может сохранить настройки из текста вопроса.

Один обычный запрос сначала создаёт основной текст, затем необязательный JSON.
Служебная часть отделяется, проверяется и форматируется приложением. Нет
отдельного внешнего сервиса или API-вызова; выходной лимит не повышается.
Инструкция увеличивает входной контекст; замечания используют оставшийся
выходной объём. При нехватке места блок пропускается.

## Автоматическая проверка

Полный прогон: **590 тестов прошли**, 294 upstream DeprecationWarning из
slixmpp-omemo. Прошли `pip check`, сборка wheel 0.3.5, проверка содержимого
пакета и entry points, компиляция Python, `bash -n`, TOML-примеры,
внутренние ссылки и `git diff --check`. Обычные тесты запрещают сеть.

Проверены синтетические русский, английский, французский и смешанный текст,
неопределённый язык, слова из цитат/кода/URL/формул/условия, придуманный фрагмент,
смена числа/имени/отрицания, дедупликация и лимиты. Правильность лингвистического
содержания подставной модели не выдаётся за проверку реального провайдера.

Проверены права владельца, неизвестные адреса, запрет resource в цели команды,
ошибочные настройки без частичной записи, независимость двух детей,
сохранение при повторной инициализации/очистке и атомарная миграция 4 → 5.
Идентичность, история, профиль, город и режим после миграции сохраняются.

Для основного ответа проверены сломанный/обрезанный JSON, неподходящие поля,
отсутствие замечаний, недопустимый XML только в хвосте, отсутствие места и
просьба без исправлений. Основной ответ не обрезается ради комментариев.
Полный текущий образ с бюджетом 9000 и ближайшим контекстом прошёл тест.

Запоздалый API-ответ после manual, очистки, смены класса/языковой настройки
или hold не отправляется; второй диалог продолжает отвечать. Архив,
повторная доставка и команды не порождают разбора. В настоящем XMPP-обработчике
с подставным шифрованием проверены один вызов модели, итоговый зашифрованный
текст без меток, лайк правильному сообщению и завершение набора.

## Установленный пакет и миграция

Сценарий `tests/integration/check_language_upgrade.py` успешно выполнен на
отдельной установке в /tmp из чистых коммитов. Старый install.sh поставил
настоящий wheel 0.3.4; созданы синтетические профили, история, город,
состояние OMEMO, разные manual/auto и включённое локальное копирование.
Затем уже зарегистрированный goose-update установил 0.3.5.

В локальном режиме обновлятор не запускает XMPP. Первый рабочий запуск
воспроизведён вызовом штатного Database.initialize установленного пакета:
схема 4 → 5, все строки прежних таблиц совпали. Байты config/env/persona
и настроек/service/timer копирования сохранены. Git origin был локальным,
pip загружал зависимости по lock с проверкой хешей; приложение в сеть не ходило.

Из нового установленного пакета команды владельца включили detailed/max_notes=3
одному профилю, второму сохранили выключенное состояние; обычный аккаунт получил
отказ. Повторная инициализация сохранила настройки.

Старая регулярная копия схемы 4 прошла restore-test новым приложением:
мигрировал только временный клон, исходная SQLite сохранила схему 4 и SHA-256.
Новая проверенная копия содержит схему 5 и языковые настройки; её restore-test
также успешен. Установленный `pip check` прошёл. Настоящий systemd в этом
сценарии не запускался; рабочий VDS и его ключи не использовались.

## Исправление 0.3.6

профиль, правила лайка, два развёрнутых ответа и короткие вопросы помещались
без разбора (оценка 7475), но прежняя инструкция увеличивала оценку до 9851
при бюджете 9000. Инструкция сокращена с 2344 до 1347 UTF-8 байт и объединена
с общими правилами в первом system-сообщении; для того же синтетического
контекста оценка 8824. Регрессионный тест проверяет оба недавних
ответа, полный образ, наличие правил лайка и включённый разбор в бюджете.

Модели дано прямое указание проверить последнее сообщение и вернуть notes:[]
при отсутствии уверенных замечаний, сохранив основной ответ. Это уточнение
инструкции, а не доказательство поведения Alice AI LLM Flash. Новые безопасные
логи различают запрос разбора, отсутствие/ошибку JSON, пустые/отфильтрованные
замечания, ограничение объёма и успешное добавление. Тесты проверяют отсутствие
приватных данных в диагностике: фрагменты, правила, JID и ответ API не печатаются.

Полный прогон исправления: **598 тестов прошли**, 294 upstream предупреждения.
Новые проверки покрывают наполненное окно с полным образом и лайком, причины
пропуска/добавления и отсутствие приватных значений в журнале.

На отдельной ранее настроенной установке проверен настоящий goose-update

## Живой пилот 0.3.6 и исправление 0.3.7

Владелец установил 055c525: XMPP готов, auto готово=2, paused=0, manual=0.
В новом ответе языкового блока не было. Журнал подтвердил requested, затем
filtered с format=0/change=0/source=2/duplicate=0: модель вернула два замечания,
но их исходные фрагменты не найдены в текущем вопросе. Для этого запроса
причина — проверка source, не лимит контекста. Значения source модельного ответа
не логировались; конкретное различие их написания не установлено.

В 0.3.7 введены нумерованные слова текущего вопроса в том же запросе модели.
Модель указывает диапазон start/end; приложение извлекает исходный текст
само и применяет прежние ограничения к нему. Никакого угадывания написания
или подмены исходного вопроса нет. Текстовый source сохранён как совместимый
формат с однозначным сопоставлением е/ё, регистра, внешних кавычек и пробелов.

Новые тесты проверяют именно текущую таблицу при похожих старых вопросах,
извлечение слова/диапазона с настоящими пробелами, ошибочные индексы и отсутствие
обхода цитат/кода/URL/имён. Пять регрессионных случаев представления source
падали на 0.3.6. Изменения написания не угадываются, неоднозначность отбрасывается.
Настоящий XMPP-обработчик с подставным шифрованием проверяет индексный формат,
один запрос модели, обычный ответ, замечания, лайк и завершение набора.

Полный прогон 0.3.7: **629 тестов прошли**, 294 upstream предупреждения.
Обычные тесты запрещают сеть; точность настоящей модели ими не доказывается.
При тесном окне можно убрать более старый непарный ответ, сохранив предыдущий
обмен и текущий вопрос. Это также проверено с полным образом и правилами лайка;
необязательная инструкция не вытесняет сам новый вопрос.
