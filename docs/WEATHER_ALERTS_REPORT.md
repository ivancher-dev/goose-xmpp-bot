# Отчёт 0.3.14: погода и уведомления

Реализован [запрошенный этап](tasks/02b-weather-resilience-alerts.md):
последовательный пул Open-Meteo/wttr.in, настройка 1–3 ежедневных сводок,
местный часовой пояс города, приветствия и простые советы из погодных фактов.
Утро 08:00, день 13:00, вечер 18:00; свои часы и отключение — командами.
По выбору владельца рассылка работает и в manual, без вызова модели.

Новый набор подписки полностью заменяет прежний. Настройки разделены по bare JID;
чужую подписку меняет только владелец. Отправка использует прежний OMEMO-транспорт.
Смена города/подписки или отключение отменяет ещё не отправленную старую сводку.
SQLite 7 → 8 сохраняет данные и добавляет подписки/отметки попыток.

## Границы

Базовая установка и работа уведомлений подтверждены владельцем, расширенный
живой пилот остаётся. Погодный пул имеет два независимых сервиса;
реальное переключение на второй при отказе первого нужно подтвердить. Геокодер один.
Нет гарантии доставки при общем отказе сети. Отметка перед отправкой защищает
от повторов ценой возможного пропуска при аварии. Опоздание ограничено 10 минутами.
Дневные минимум/максимум ветра не доказывают одновременный холод и ветер;
советы сформулированы условно. Прогноз остаётся на сутки, не только на остаток дня.
