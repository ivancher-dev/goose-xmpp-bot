# Расширение этапа 3: образ, набор и реакции

По запросу владельца, без расписания и новых внешних API.

- Расширить образ рассказами древнего Императора Вселенной от первого лица:
  путешествия разных эпох, домашние переоткрытия, Гусинландия. Сохранить
  позитивность, диван, Синтепониум и прежние способы шутить. Убрать обязательную
  ссылку на летописи; верно объяснять механизм. Настоящий автор появляется
  только после нового вопроса об авторстве. Фактическая справка и просьба
  без шуток дают правдивый ответ сразу; неоднозначность признаётся.
- Обновление внешнего образа заменяет только раздел об изобретениях,
  сохраняет остальные правки владельца и создаёт защищённую копию.
- Добавить опциональный XEP-0085: composing во время подготовки ответа модели,
  active после завершения, ошибки, паузы, очистки и отмены. Не оставлять
  старый статус после начала нового задания; задачи завершаются при disconnect.
- При нескольких клиентах индикатор адресуется полному JID устройства вопроса;
  queued-задание и его финализатор сохраняют этот адрес. Учитываются отдельные
  живые уведомления состояния в ограниченном кэше ресурсов, без команд, истории
  и обхода OMEMO/доверия. Профили, режимы и память остаются привязаны к bare JID.
- Добавить опциональные XEP-0444 реакции 👍 на интересные вопросы по оценке
  модели в том же запросе. Внутреннюю метку не отправлять в текст/память.
  Не чаще одного лайка за пять вопросов и пять минут своего диалога в сессии.
- Привязывать реакцию к origin-id, затем к id доверенного живого входящего
  сообщения. Нет ID — нет лайка. Команды, архив, повторы, manual и отменённые
  задания реакций не создают. Другие пользователи изолированы.
- Чистые служебные состояния и реакции (включая fallback-body реакций) не исполняются как
  команды и не считаются ручным текстом. Реакции из MAM не включают manual.
  Текст ответов остаётся OMEMO; уведомления состояния/реакции — отдельные
  служебные XMPP-метаданные. В статусе набора нет содержимого вопроса.
- Старые конфиги продолжают работать: обе функции выключены до явного
  включения. Схема 4 и зависимости сохраняются. Для расширенного образа
  рекомендован memory.context_token_budget=9000 (оценка по UTF-8 байтам).
- Проверки без сети: XML на установленном Slixmpp, отмена при API/шифровании,
  запоздалый ответ, повторы, MAM/Carbons, изоляция, лимиты лайков,
  сохранность внешнего образа. Обычный тест не проверяет качество реальной
  модели; живая приёмка Gajim/Conversations и двух ходов описывается отдельно.
