# Задача № 3: совместная переписка и восстановление

Основание: этап 3 [ROADMAP.md](../ROADMAP.md), разделы 5–8 [SPEC.md](../SPEC.md).

- Подтверждённое исходящее сообщение другого устройства Гуся ставит только
  соответствующий разрешённый диалог в manual, отменяет неотправленные ответы
  модели и инструментов. Собственные ответы сервиса этого не делают.
- Проверяются отправитель и получатель оболочки Carbons, направление,
  единственность forwarded/message, тип, вложенные оболочки и OMEMO-устройство.
  Отправка владельца не становится командой и не запускает генерацию.
- Между получением возможного ручного сообщения и его проверкой действует
  временный запрет отправки в этот диалог. Уже отправленное сообщение не отзывается.
- Ручная переписка попадает только в историю своего bare JID. Очистка контекста
  не позволяет последующей синхронизации вернуть удалённую память.
- MAM загружается ограниченными страницами отдельно для разрешённых диалогов.
  Результаты связаны с активным запросом, проверяются адреса, структура, время,
  ID страниц и завершённость. Архив не запускает команды, API модели или погоды.
- Постоянные позиции архива и хеши идентификаторов предотвращают повторную
  обработку live/Carbons/MAM и отличают ответы сервиса после перезапуска.
  При утраченной позиции, неполной выборке или ошибке расшифровки автоматическое
  восстановление auto запрещено; владелец может подтвердить его явно.
- При первом обновлении устанавливается новая исходная позиция архива без
  импорта старой переписки. Нужен один явный auto; затем при успешной
  синхронизации и наличии Carbons прежний auto восстанавливается автоматически.
- Схема SQLite 4 сохраняет профили, память, города, OMEMO и доверие.
  Обновление требует свежей защищённой резервной копии; откат схемы запрещён.
- Проверки используют временные БД, подставные XMPP/MAM и настоящие тестовые
  OMEMO-ключи. Проверяются подделки, оба порядка доставки, отмена во время API
  и шифрования, независимость диалогов, обрыв/перезапуск и архив без автоответов.
- Отдельно документируются установка 0.3.0, живой пилот Gajim/Conversations,
  версии API и ограничения восстановления/сетевой задержки. Расписание,
  изображения и автоматическое обновление сервера в этот этап не входят.
