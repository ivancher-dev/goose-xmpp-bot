# Пул погоды и добровольные уведомления

По запросу владельца 3 ноября 2026 года, перед школьным расписанием.

1. При недоступности/непригодном ответе погодного сервиса переходить к следующему.
   Ограничить время перебора; не отключать TLS и не придумывать погоду при полном отказе.
2. Через команды выбирать количество уведомлений и время, как свой город.
   По умолчанию: утром 08:00, днём 13:00, вечером 18:00. Часовой пояс города.
3. Добровольная рассылка отдельно по bare JID, сохраняется после перезапуска.
   Владелец может настроить разрешённого собеседника, пользователь — только себя.
4. По явному выбору владельца присылать погоду и в manual; не включать auto,
   сохранять отмену обычных ответов, использовать прежний OMEMO-транспорт.
5. Приветствие по периоду; советы из фактов: зонт при дожде, тёплая одежда в холод,
   шапка ниже +8 °C с ветром. Пороги и ограничения описать.
6. Ограничить пропущенные/повторные отправки. Смена города или подписки отменяет
   старую готовящуюся сводку. Миграция сохраняет прежние данные.
7. Офлайн проверить отказы, часовые пояса, права, изоляцию, перезапуск, отмену
   во время шифрования и восстановление. Живую приёмку не выдумывать.
