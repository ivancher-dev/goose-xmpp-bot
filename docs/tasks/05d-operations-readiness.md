# Приёмка постоянной эксплуатации

По уточнению владельца от 03.11.2026 Гусь уже работает на основном аккаунте.
Внешних копий пока нет. Этот этап вынесен вперёд; расписание ждёт публикации сайта.

1. Зафиксировать фактическое использование основного аккаунта без повторного
   переноса и без изменения действующих режимов/получателей.
2. Проверить имеющиеся механизмы автозапуска/готовности/перезапуска, копирования,
   хранения, ограничений запросов и диагностики по исходникам и прежним отчётам.
3. Получить с VDS сводку службы, копирования, памяти и диска. Отделять результаты
   кода/тестов от наблюдений владельца и текущих измерений.
4. Подтвердить календарные копии и пробное восстановление актуального клона.
   Определить независимое внешнее хранение до настройки передачи секретных копий.
5. По измерениям определить эксплуатационные ограничения и оставшиеся
   проверки; тариф/дневные лимиты API не придумывать.
6. Прерывающие проверки, перезагрузку VDS и замену рабочей БД не включать
   в обычный сбор состояния. Не подключать второй клон той же идентичности OMEMO.
7. Сохранить результаты и оставшиеся вопросы в [отчёте приёмки](../OPERATIONS_READINESS.md).
