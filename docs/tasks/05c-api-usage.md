# Учёт использования API, 0.3.11

По выбору владельца: сначала только статистика. Дневные лимиты — отдельная задача.

- Учитывать автоматические обращения модели по нормализованному bare JID.
  Сводка владельцу за день/месяц и явно выбранную дату/месяц.
- Различать обращения и отдельные HTTP-попытки, включая повторы, отмену,
  ошибочный ответ API и расход, не завершившийся доставкой сообщения.
- Брать токены из usage провайдера; неизвестные/неверные значения не считать нулём.
  Тексты, ключи и содержимое HTTP-ошибок не писать в статистику и журнал.
- Сохранять учёт между перезапусками/обновлениями и очисткой памяти.
  Миграция схемы 5 → 6 сохраняет профили, OMEMO, режимы и таймер копирования.
- Денежная оценка только по явно заданному текущему тарифу модели/провайдера;
  неполноту и отличие от счёта провайдера показывать явно.
- Проверить изоляцию параллельных аккаунтов, права команд, отмену, ретраи,
  отсутствие данных usage, границы суток/месяцев и пробное восстановление.
