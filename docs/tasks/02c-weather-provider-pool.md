# Пять погодных источников, 0.3.15

Запрос владельца 05.11.2026: уведомления снова пропадали при недоступности погоды.
Внешнюю резервную копию пока отложить; вернуться к устойчивости погодного пула.

1. Выбрать 4–5 публично документированных источников с широким покрытием,
   включая российский. Владелец согласился получить бесплатный личный ключ Яндекса.
2. Последовательно пробовать следующий сервис при таймауте, HTTP/сетевой ошибке,
   устаревших, неполных или непригодных данных. Ограничить отдельный и общий срок.
3. Сохранить основной источник и явно заданный резерв. Без явного резерва
   подключать остальные сервисы; отсутствие ключа не задерживает пул.
4. Сохранить команды города и уведомлений, местный часовой пояс, 08/13/18,
   работу рассылки в manual, проверки прав/OMEMO, отмену и защиту от повторов.
5. Не выдумывать наблюдения, вероятность осадков, точный ветер и суточные
   экстремумы, если формат источника их не предоставляет. Советы — из данных.
6. Учесть личный лимит Яндекса, условия доступа MET Norway и защиту ключа.
   Не получать чужие ключи и не разбирать погодные HTML-страницы вместо API.
7. Проверить офлайн все переходы до пятого источника, повреждённые данные,
   часовые пояса, очередь уведомлений, сохранение данных при обновлении.
   Живую доступность с VDS и точность для города проверять отдельно.
