# Временный перехват 0.3.12: проверки

Реализованы возврат прежнего auto после минуты тишины владельца и отдельная
оценка недавних живых вопросов. Явный manual постоянный. Схема 6 → 7.

Полный прогон: **755 тестов прошли**, 296 прежних upstream DeprecationWarning.
Из них 42 проверки нового поведения прошли отдельно.

Автоматически проверены: таймер каждого диалога, новые ручные сообщения,
дубликаты, постоянный manual, разрыв соединения/неполный архив, holds,
возврат без нового сообщения, перевод системных часов, перезапуск с паузой,
вопрос до перехвата и во время него, уже отвеченный вопрос, одно общее
продолжение, сомнительный/невалидный JSON, нечитаемый текст и переполнение
контекста. Новые вопросы и ручные сообщения во время оценки/шифрования
блокируют поздний ответ даже при игнорирующем отмену API. Повторная доставка
вопроса не отменяет действительную оценку.

Подставной HTTP проверяет две строки usage для оценки и продолжения.
Проверены миграция схемы 6 с сохранением manual/auto, ключей и статистики.
Тестовые резервные копии содержат незавершённую временную паузу и статистику.
Продолжение сохраняется отдельной репликой после ручных сообщений; связь
с отвеченными вопросами предотвращает их повторную оценку. Очистка памяти
удаляет эти связи. Пауза и отметки ответов также входят в копии.

Обычные тесты запрещают исходящие соединения. На VDS версия не установлена;
семантические решения настоящей Alice AI, таймеры в Gajim/Conversations
и отсутствие повторов в живом чате ещё не проверены.
