# Учёт API 0.3.11: проверки

Реализована статистика автоматических запросов по собеседникам. По выбору
владельца новых дневных ограничений нет. Схема SQLite повышается 5 → 6.
Данные ключей, профилей, режимов, языка и прежней памяти сохраняются.

Полный прогон: **713 тестов прошли**, 296 upstream DeprecationWarning.
Проверены права и разделение аккаунтов, параллельные запросы через общий
HTTP-клиент, повторы одного обращения, отмена и готовый API-ответ после ручной
паузы, местный rate limit без HTTP. Есть проверки неизвестного/частичного/
неверного usage, внутренних cache/reasoning счётчиков без двойного сложения,
чужого тарифа и отсутствия цен, суток DST, месяца и локальной полуночи.

Проверены очистка контекста без потери статистики, перезапуск с прерванным
запросом, идемпотентное завершение попытки, ограничение хранения с сообщением
о неполноте и миграция 5 → 6 с откатом транзакции при ошибке.
Тестовые резервные копии теперь содержат статистику; прежние проверки
целостности, восстановления, холодного OMEMO и атомарности продолжают выполняться.

Обычные тесты запрещают исходящие соединения, все API/тарифы синтетические.

На отдельной временной установке выполнен настоящий goose-update с 0.3.10
(4c200a9, схема 5) на 0.3.11 (7f2dc49, схема 6). Установлены зависимости с
хешами и пакет из wheel. Профили, память, языковые настройки, manual/auto,
OMEMO-данные, конфигурация, образ и файлы таймера сохранены. Установленный
пакет записал синтетический API-ответ с 13 токенами; сводка и права проверены.
Новая резервная копия содержит эту статистику. Пробное восстановление копий
схем 5 и 6 прошло; исходная копия схемы 5 не изменилась. pip check успешен.
В этой проверке нет настоящего XMPP, API или системного systemd.

Дополнительно прошли 91 целевая проверка учёта/конфигурации, compileall,
синтаксис shell, проверка внутренних ссылок, TOML и git diff --check.

На VDS новая версия не устанавливалась; реальный usage Alice AI и денежная
оценка требуют пилота после установки. Действующие цены провайдера не задавались.
